
# Go Project-Based Learning

A practical learning repository focused on mastering Go (Golang) through hands-on exercises and backend development projects.

## Learning Objectives

- Understand Go fundamentals and syntax.
- Learn Go programming concepts and concurrency.
- Build RESTful APIs using Go.
- Integrate PostgreSQL databases.
- Implement authentication and authorization.
- Apply clean architecture and software engineering best practices.
- Develop a complete backend application.

## Learning Roadmap

1. Go Fundamentals
2. Intermediate Go
3. Advanced Go
4. REST API Development
5. Database Integration
6. Authentication & Authorization
7. Unit Testing
8. Final Project: Event Management API

## Technology Stack

- Go
- Gin
- PostgreSQL
- JWT
- Docker
- Swagger

## Learning Approach

Project-Based Learning with GitHub Copilot as a coding mentor.
